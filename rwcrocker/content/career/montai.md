## Summary
I build the core data platform at Montai, working with a team of analysts, engineers, and scientists.

## Institution

[Montai Therapeutics](https://www.montai.com/) is a machine-learning drug discovery start-up in Cambridge, MA. The company is trying to predictably discover small-molecule therapeutics for chronic disease.

## Responsibilities

* Built a cloud data warehouse that brings together ontologies, chemical metadata, assay results, and ML predictions
* Run Python and SQL ETL pipelines for terabyte-scale scientific data, with orchestration to keep datasets fresh and reproducible
* Build web apps for key workflows:
    * A tool for picking which compounds to take forward from high-throughput screens, guided by ML
    * A data catalog with a natural-language-to-SQL agent, so people can find data themselves
    * A chemical space explorer for comparing outside data against our own results
* Write analyses, reports, and dashboards for data engineers, biologists, leadership, and investors
